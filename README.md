## Tema general
Video introductorio a un curso completo de programación en lenguaje ensamblador para procesadores Intel 8086. Presenta objetivos, herramientas necesarias y metodología a seguir para aprender a desarrollar algoritmos sin usar librerías externas.

## Qué se explicó / enseñó
- Objetivo del curso: aprender ensamblador desde cero para resolver problemas de consola y modo video.
- Perfil del estudiante: autodidactas, apasionados de la programación, interesados en el bajo nivel.
- Metodología: enfoque práctico sin librerías externas, para entender el funcionamiento interno.
- Estructura del curso: 19 capítulos (17 en modo consola, 2 en modo video).
- Justificación del curso: experiencia personal del instructor sobre la dificultad de encontrar buen material de ensamblador.

## Qué se hizo (paso a paso)
1. Presentación verbal del temario del curso.
2. Muestra de ejemplos visuales de proyectos finales: un juego tipo Tetris y un sistema de gestión de usuarios.
3. Explicación de la configuración técnica: DOSBox como emulador del entorno 8086, MASM (Microsoft Macro Assembler) como ensamblador.
4. Mención de Emu8086 como herramienta adicional de depuración (debugger).
5. Anuncio de la creación de un repositorio en GitHub para alojar el código del curso.

## Herramientas / tecnologías mencionadas
- Lenguaje ensamblador (arquitectura Intel 8086)
- DOSBox
- MASM (Microsoft Macro Assembler)
- Emu8086
- GitHub

## Problemas o errores
No hubo errores técnicos durante el video; es un video introductorio informativo.
